# Sports Platform:

Modern sports management platform built with Java and Spring Boot.

## Project Goals

This project is a portfolio project designed to demonstrate modern
backend development practices and technologies.

## Architecture

The platform will be based on a microservices architecture and will
follow Hexagonal Architecture and API First principles.

## Technologies

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- REST API
- OpenAPI
- JUnit 5
- Mockito
- Docker
- Kafka
- Spring WebFlux
- Prometheus
- Grafana
- SonarQube
- Kubernetes
- CI/CD
